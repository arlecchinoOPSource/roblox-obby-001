# Roadmap

Project 001 is active. [Studio smoke verification](https://github.com/arlecchinoOPSource/roblox-obby-001/issues/2) is the remaining check for [the setup review](https://github.com/arlecchinoOPSource/roblox-obby-001/pull/1). Each later milestone requires a separate assignment.

| Milestone | Scope | Exit check |
| --- | --- | --- |
| [Project 001](https://github.com/arlecchinoOPSource/roblox-obby-001/milestone/1) | Verify the pinned Rojo toolchain, source layout, and smoke test | A fresh build opens in Studio, both smoke messages appear, a disk edit syncs into a second playtest, Script Analysis is clean, and the place saves and reopens locally |
| [First playable prototype](https://github.com/arlecchinoOPSource/roblox-obby-001/milestone/2) | Agree on the scope, build a short greybox course, and add server-owned progress | A player can earn a checkpoint, recover after falling, and reach the finish |
| [Multiplayer and polish](https://github.com/arlecchinoOPSource/roblox-obby-001/milestone/3) | Test progress with two clients and review first-run clarity on desktop and touch | Progress stays independent, the server rejects invalid progress, and players can complete the course using either control scheme |
| [Commercial release](https://github.com/arlecchinoOPSource/roblox-obby-001/milestone/4) | Review readiness, asset provenance, and optional monetization | The owner records the release decision. Publishing and enabling real purchases each require separate authorization |
